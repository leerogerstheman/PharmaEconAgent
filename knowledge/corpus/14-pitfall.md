## 一、计算与报告类

| 陷阱 | 表现 | 正确做法 |
| --- | --- | --- |
| **只比 ICER 不看平面** | 新方案在西南象限仍被推荐 | 先判象限，再谈 ICER |
| **阈值当自然常数** | "ICER<5万即可接受" | 报告 CEAC，把阈值选择权交给读者 |
| **对 PSA 结果求平均 ICER** | 报"平均 ICER = X" | 改报可接受概率与 NMBA |
| **效果未折现 / 成本与效果折现率不同** | 三种做法混用 | 统一折现率并做 0%–8% 敏感性分析 |
| **成本用标价不用净价** | 高估新药成本 | 用可得净价，或做价格敏感性分析 |
| **CHEERS 条目量化打分** | 给报告"打了 72 分" | 只做定性完整性描述 |
| **单位混乱** | "元/年" 与 "元/QALY" 混算 | ICER 分子分母口径必须一致 |

## 二、研究设计类

### 对照方案（参照药）选择不当

- 用安慰剂作对照，而不是**现有最优治疗** → 系统性高估新药价值
- 选一个明显劣于现有治疗的对照 → 同上
- 中国语境下更严重：企业自选参照药，评审确定的参照药若不同，报告可能失去参考价值
- **正解**：对照方案要与决策者提前对齐，论证选择理由（CHEERS 条目 7）

### 研究视角不一致

- 声明社会视角却只算直接医疗成本 → 结果偏低
- 视角混用且不并列报告 → 无法解释
- **正解**：明确声明视角，并做视角的敏感性分析

### 研究时限过短

- 慢性病只算 1 年，无法体现长期获益
- **正解**：时限应反映疾病自然进程；长期模型通常用终身

### 未做依从性调整

- RCT 中依从性高，真实世界更低 → 实际效果与成本都会变
- **正解**：主分析用真实世界依从性，或做依从性敏感性分析

## 三、数据与参数类

| 陷阱 | 说明 |
| --- | --- |
| **照搬国外效用值** | 未做本地化校准，人群差异可能很大 |
| **参数可移植性差** | 转移概率、依从性、单价都受卫生体系影响（见 Drummond 2009 可移植性研究） |
| **效用值未做质量核查** | ISPOR 2019 报告点名："常引用过时的 HSU，却未核查人群相关性、效用工具、偏好引出方法" |
| **把不同方法的 HSU 拼凑** | 会使结果无法解释 |
| **成本数据年份不统一** | 价格年、价格指数、汇率必须统一并声明 |
| **数据来源不分等级** | 应按证据等级排序：真实世界数据 > 高质量 RCT > 观察性研究 > 专家意见 |

## 四、模型类

| 陷阱 | 说明 |
| --- | --- |
| **周期长度不当** | 太长掩盖状态内质量损失；太短计算量爆炸 |
| **转移概率时间尺度不一致** | 用年转移率跑月度周期 |
| **终止状态设置错误** | 死亡后又回到健康状态 |
| **未做模型校准/验证** | 至少应与已发表研究结果比对 |
| **未做外部验证** | 用另一来源数据验证模型输出 |
| **半周期校正未说明** | 是否使用、如何使用要写清 |

## 五、高级陷阱

### 混合治疗（combination therapy）

- 当对照是"新药 A"、干预是"A + B" 时，ICER 反映的是**增加 B 的价值**，而不是"整体方案 A+B vs 现状"的价值
- 若目的是评估换用 A+B 的完整方案，对照应是"现状治疗"
- **正解**：明确 ICER 回答的是哪个问题，并做情景分析

### 网络 Meta 分析（NMA）的间接比较

- 间接比较依赖**传递性假设（transitivity）**——不同试验间患者特征、结局定义、随访时间必须可比
- 结果对**间接比较的调节变量**（效应修饰因子）非常敏感
- **正解**：报告 NMA 的不一致性检验结果，并说明哪些是直接证据、哪些是间接推断

### 增量分析的符号

- `ΔC` 与 `ΔE` 的符号必须与文字描述一致
- 出现"新方案更贵、效果更差"却算出负 ICER 并推荐 → 结论与数据矛盾
- **正解**：报告前先检查平面象限

## 六、伦理与公平性

- 只报平均值，忽略**分布效应**：新药是否主要惠及最贫困/最严重的人群？
- 未考虑**患者的支付能力**（中国存在显著的自费压力差异）
- **正解**：CHEERS 2022 条目 19 要求表征分配效应

## 批判性阅读训练法

拿到一篇药物经济学论文，按这个顺序审：

1. 对照方案是谁选的？为什么？
2. 视角是什么？四种成本都算了吗？
3. 效果指标怎么测的？效用值从哪来、有没有做质量核查？
4. 时间范围和折现率是多少？做过敏感性分析吗？
5. 模型结构是什么？校准了吗？
6. 不确定性怎么处理的？报告了 CEAC 吗？
7. 按 CHEERS 28 条逐条对照，缺哪些？
8. 结论和数字一致吗？
