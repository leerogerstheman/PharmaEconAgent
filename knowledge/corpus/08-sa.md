任何经济学评价都建立在**假设**之上。参数不确定 → 必须做敏感性分析。

## 三个层次

| 方法 | 中文 | 变的是什么 | 输出 | 什么时候用 |
| --- | --- | --- | --- | --- |
| OWSA | 单因素敏感性分析 | 每次只改 1 个参数 | 龙卷风图 / 排名 | 快速找出关键参数 |
| DSA | 确定性敏感性分析 | 多个参数按**特定规则**一起变 | 阈值区间 | 参数有已知关联时 |
| **PSA** | 概率敏感性分析 | 所有参数按**概率分布**随机抽样 | CEAC、概率分布 | **必做，主流报告要求** |

## OWSA 单因素敏感性分析

每次只让一个参数在"低值"和"高值"之间变动，其余不变。

```
新参数 = 基准值 + 该方向上的改变量
```

对每个参数计算：
- 低值下的 ICER / INMB
- 高值下的 ICER / INMB
- **摆动幅度**（两个 INMB 与基准 INMB 的偏差之和）

按摆动幅度排序 → 画出**龙卷风图**。

**用法**：龙卷风图告诉你"哪个参数最影响结论"，这个参数就是后续 PSA 里最该认真做分布假设的对象。

## DSA 确定性敏感性分析

多个参数**按事先设定的规则联动**变化。常用规则：

- **预算影响分析**（BIA）：渗透率、替代率、单价按情景联动
- **临床疗效**（CE）：效果相关的参数（HR、OR、依从性）联动
- **参数**（Parameter）：由决策者指定的相关参数组
- **特定疾病**（Disease specific）：按疾病特点自定义

每个情景输出一个 ICER，报告"在哪些情景下结论会改变"。

## PSA 概率敏感性分析 —— 核心方法

对成本和效果的**每一个参数**设定一个概率分布，抽样 N 次（通常 1000～10,000），每次计算 ICER 或 INMB。

### 常用分布

| 分布 | 典型用途 | 参数写法 |
| --- | --- | --- |
| **对数正态** lognormal | 成本、单价、住院天数 | `{mean, cv}` 均值+变异系数 |
| **Gamma** gamma | 事件发生次数、住院次数 | `{mean, cv}` 或 `{shape, scale}` |
| **Beta** beta | 效用值、比例（值域 0～1） | `{mean, se}` 或 `{alpha, beta}` |
| **三角分布** triangular | 只有最小/最可能/最大三点信息 | `{low, mode, high}` |
| **均匀分布** uniform | 只有上下界 | `{min, max}` |
| **对数均匀** loguniform | 极宽范围、跨数量级 | `{min, max}` |
| **Dirichlet** | 多方案互斥时的资源分配 | 罕见 |

> `cv`（coefficient of variation）= 标准差 / 均值。药品成本常用 cv = 0.25，住院天数常用 cv = 0.3～0.4。

### CEAC 成本效果可接受曲线

横轴是阈值 λ，纵轴是"新方案在该阈值下具有成本效果的模拟比例"。

```
对每个 λ：probCE(λ) = ( 满足 INMB = ΔC − λ·ΔE > 0 的模拟次数 ) / 总模拟次数
```

读法：
- 曲线在某个 λ 处穿过 **50%** 水平线 → 该 λ 就是 **CEPT**（可接受阈值）
- 曲线整体越靠左越好（在更低的阈值下就有高概率）
- 曲线**始终很低**（< 50%）说明在合理阈值区间内证据都不支持新方案

### CERP 成本效果概率曲线（可接受概率图）

横轴仍是阈值，纵轴是 ICER 的累积分布。等价于 CEAC 的另一种画法，**不是**"某个具体 ICER 的概率密度"。

> **最常见的错误**：把"新方案比现有治疗更优的概率"误读成"某方案成为最优方案的概率"。后者需要多方案比较（用 best-arm 期望改进、PBMA 等方法）。

## 必须报告的

1. 抽样次数 N（≥ 1000，通常 1000–5000）
2. 每个参数的分布类型与参数
3. 随机种子（本软件固定 seed，**结果可复现**）
4. CEAC 曲线
5. 阈值下的可接受概率
6. NMBA / INMB 均值与可信区间

## 教学价值

PSA 是药经教学里**最能建立科学直觉**的部分：它让抽象的"不确定性"变成可视的曲线。本软件的 PSA 计算器使用固定随机种子，**同参数同种子必得同结果**，你可以放心地反复调整参数观察曲线如何移动。
