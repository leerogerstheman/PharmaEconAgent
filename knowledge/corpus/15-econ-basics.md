药物经济学是**卫生经济学**的应用分支，而卫生经济学是**微观经济学**的应用。药学学生缺的那块"经济学基础"，其实就是下面这几个概念。

## 1. 稀缺性与机会成本

**稀缺性**：资源有限，欲望无限。所有经济学问题都源于此。

**机会成本（opportunity cost）**：选择 A 而放弃的**次优选择 B** 的价值。

> 在药物经济学里，**"给新药花 10 万元" 的机会成本是"这 10 万元本来可以用来给另外 100 个人做别的治疗"**。
> 这就是为什么"新药很贵但有效"不能自动等于"值得"——要问它比把钱用在别处好多少。

## 2. 边际分析（marginal analysis）

**边际** = 增加一个单位带来的**增量**变化。

药物经济学的 ICER 就是一个边际概念：

```
ICER = 额外多花的成本 ÷ 额外多得到的效果
```

> 学生最容易犯的错：拿"总成本"和"总效果"相除。那是**平均成本效果比（ACER）**，不是 ICER。
> ACER 没有决策含义——一个极其昂贵、极其有效的方案会得到很小的 ACER，看起来"划算"，但这毫无意义。

## 3. 现值与折现

今天的钱比未来的钱更值钱（时间偏好 + 风险）。所以比较不同时间点的钱必须换算到同一时点。

```
PV = Σ CFₜ / (1+r)ᵗ
```

这个概念本身属于**金融**，但应用时用的是**社会时间偏好率**，不是市场利率——这是药物经济学里最有争议的一点。

## 4. 效用理论与效用值

**基数效用论**：效用可以数值化比较，0 = 死亡，1 = 完全健康。
QALY 用的就是这一套。

**显示性偏好（revealed preference）**：从**实际选择**推断偏好
- 例：你花 50 元买了书而不是电影，说明你更看重书

**陈述性偏好（stated preference）**：直接**问**偏好
- 例：WTP 调查、DCE（离散选择实验）、标准 Gamble、时间权衡

**陈述性偏好的偏差**：晕轮效应、假象偏差（endowment effect）、战略性回答、社会期许偏差。
→ 这就是为什么**标准 Gamble 得到的效用值常偏高**，EQ-5D 这类量表更稳健。

## 5. 风险厌恶与确定性等价

**确定性等价（certainty equivalent, CE）**：一个确定的结果，其主观价值等于一个有风险的结果。

- **风险厌恶**：`CE < 期望值`（面对风险，主观价值低于数学期望）
- 医疗领域风险特别大（疗效不确定、不良反应），所以 CE 效应明显
- 药物经济学常用**风险调整的成本效果比**（RCER）来处理：把不确定性反映进 ICER 而不是只做敏感性分析

## 6. 支付意愿（WTP）

个体愿意为一个健康改善（或一个 QALY）付出的**最大金额**。

- 微观基础：价格接受需求曲线
- 宏观阈值 λ 与 WTP 的关系：λ 大致等于社会平均 WTP
- WTP 随**收入**变化 → 存在收入弹性 → 有人提议用**一般等价弹性（GEI）**做收入调整
- WTP 分布**高度右偏**：多数人愿付不高，少数人愿付极高 → 用均值做阈值不合适

## 7. 供需与市场失灵

- 药品市场存在**信息不对称**（患者无法判断疗效）、**外部性**、**公共品属性** → 单靠市场无法配置好医疗资源
- 医保的存在就是为了纠正这种失灵
- **这解释了为什么要做 HTA**：不是市场说了算，需要政府用经济学证据辅助决策

## 8. 折现中的经济学基础

- **纯时间偏好**：1% 还是 3%？理论上应等于真实消费贷款利率
- **时间不一致性（time inconsistency）**：经济学上纯时间偏好应导致 r=0（未来和现在等价），但实证上人对未来健康支出的折现远低于对未来财务支出的折现
- 这就是"**超越死亡（beyond mortality）**"论证：在健康与生命方面，r 应当接近 0

## 概念对照速查

| 经济学概念 | 在药物经济学中的对应 |
| --- | --- |
| 机会成本 | 新药的成本 = 放弃的其他治疗的价值 |
| 边际分析 | ICER（而非 ACER） |
| 现值 | 折现后的成本与效果 |
| 效用（基数） | 效用值 0–1、QALY |
| 显示性偏好 | 实际市场数据 |
| 陈述性偏好 | WTP 调查、Gamble、TTO |
| 确定性等价 | RCER 风险调整 |
| 市场失灵 | HTA 存在的理由 |

## 学习建议

不需要先系统学完微观经济学。读药物经济学教材的第 2–3 章（经济学基础），比直接读《微观经济学》更快，因为教材已经把概念放到了应用场景里。
