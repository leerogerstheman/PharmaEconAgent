## 选哪种模型

| 情形 | 推荐模型 |
| --- | --- |
| 病程短（< 1 年）、一次性决策、结局明确 | **决策树** |
| 慢性病、需长期随访、疾病会复发/进展、状态可循环 | **Markov 模型** |
| 需要刻画个体差异、随访数据不足 | **个体队列模型 / microsimulation** |
| 疾病状态有持续时间要求（如急性发作期） | **半马尔可夫模型** |

## 决策树

从**决策节点**（方形）出发，沿**分支**（线）走到**机会节点**（圆形），最后到**终点**（三角形）汇总成本与效果。

- 适合短期、路径清晰的问题
- **每条路径的末端必须有一个汇总终点**，把所有成本和效果加总
- 可用于计算 **EVPI / EVSI**（见下）

## Markov 模型

把疾病过程拆成若干**健康状态**（如"无病 / 轻症 / 重症 / 死亡"），计算在每个周期内状态之间的**转移概率**。

### 队列模型（cohort）vs 队列模拟（microsimulation）

| | Markov 队列模型 | 队列模拟 / microsimulation |
| --- | --- | --- |
| 追踪方式 | 追踪"一整群假想患者"的比例 | 追踪一个个具体个体 |
| 内存需求 | 低 | 高（需大量个体） |
| 可处理异质性 | 较难 | 容易（可按亚组分别跑） |
| 随机性 | 固定转移概率 | 每次运行结果略有不同 |

**初学与多数报销场景用队列模型即可**，结论稳定、可复现。

### 周期长度（cycle length）

- 原则：周期要足够短，能体现健康状态的变化；又不能太短，否则计算量爆炸
- 常用：1 年、3 个月、1 个月
- **慢性病状态变化慢 → 周期可长（1 年）**；急性发作频繁 → 周期要短

### Half-cycle correction（半周期校正）

Markov 模型假设**状态转换只发生在周期边界**。这会人为延后事件发生。半周期校正假设事件在周期内均匀发生，把成本和效果**折半**（成本取半、效果也取半）后再累加。

- 影响很小，但**正式模型通常应做**
- 在软件中作为一个开关提供

## 校准（calibration）

模型算出的结果与**真实世界观察数据**不一致时，需要调整参数使两者吻合。

- 常见目标：与已发表的经济学评价结果一致、与临床试验的 HR/OR 一致
- 常用的两个校准指标：
  - `平均绝对误差 MAE = Σ|观察值 − 预测值| / 观察数`
  - `均方根误差 RMSE`

## 价值信息分析：EVPI 与 EVSI

**EVPI（完全信息期望值）**：如果能**完全确定**结局，最多愿意花多少钱去获得这个信息。

```
EVPI = max_策略( E[价值 | 完全信息] ) − max_策略( E[价值 | 现有信息] )
```

**EVSI（样本信息期望值）**：如果能通过**进一步研究**部分减少不确定性，最多愿意花多少钱。

```
EVSI = max_策略( E[价值 | 部分信息] ) − max_策略( E[价值 | 现有信息] )
```

### 决策含义

- `EVSI > 研究成本` → **值得做这项研究**
- 这是回答"要不要做临床试验 / 要不要做调研"最有力的经济学工具
- 常见结论：成本效果结果已经非常确定时，EVSI 很小，不值得追加昂贵试验

## 易错点

1. **周期太长**掩盖了状态内的质量损失，导致 QALY 被低估。
2. **转移概率的时间不一致**——用一年的转移率跑月度周期。
3. **终止规则（absorbing state）设置错误**，导致死亡后又回到健康状态。
4. **只跑了基础分析没跑 PSA**，审稿人几乎必然会要求补做。
5. **模型结构未与来源文献对齐**——必须引用你参考的已发表模型的 PUBLISHER / 结点结构说明。
