药物经济学智能体 —— 使用说明
================================================

【这是什么】

一个帮你学药物经济学、帮你算药物经济学数据的软件。
面向药学和经济学的同学，不需要你会用电脑，也不需要装任何东西。


【怎么打开】

1. 双击本文件夹里的  药物经济学智能体.exe
2. 等 3～10 秒（第一次可能慢一点，因为要解压）
3. 窗口打开就可以用了

第 1 次打开时，Windows 可能弹出蓝色的"已保护你的电脑"提示：
  → 点"更多信息" → 点"仍要运行"

这是因为软件没有购买商业代码签名证书，不是病毒。
如果不放心，可以先用杀毒软件扫描一下。

⚠ 重要：不要只把 exe 单独复制走，要整个文件夹一起复制/解压。


【第一次要做什么】

什么都不用配置，直接用。

打开后，左边有 9 个按钮，从上到下分别是：

  智能问答   ← 从这里开始。用大白话问问题
  计算器     ← 算数的地方，别手算，用这个
  知识库     ← 想看原文的时候
  术语表     ← 遇到看不懂的缩写
  公式       ← 查公式和算例
  学习路径   ← 零基础系统学，13 步
  自检清单   ← 交作业前自查
  延伸阅读   ← 书籍和论文
  历史记录   ← 你问过什么

最下面还有一个"设置"。


【四个最常用的功能】

■ 1. 问问题

  在左下角的框里打字，然后按 Enter。

  · 用大白话问就行，不用学术语言
  · 不知道问什么？看欢迎页上的 4 张卡片，点一下就问
  · 回答下面有"？问号"的按钮，点一下就能接着问
  · 回答里的"药物经济学智能体"下面有一行小字，
    点"查看思考过程"能看到软件是怎么查资料、怎么算的

  三种回答方式怎么选：
    直接回答     —— 单个问题，最快，默认用这个
    先规划再解答 —— "帮我完整分析一个药"这种多步骤任务
    回答后自查   —— 检查作业，会再校一遍公式和结论

■ 2. 算东西

  左边点"计算器"，选一个工具，填数字，点"开始计算"。

  · 每个输入框上面都有中文标签，右边有单位
  · 框上面灰色的那行是提示，告诉你该填什么
  · 填错了会明确告诉你"哪一项错了、应该怎么填"
  · 结果下面有"怎么理解这个结果"，会讲背后的道理
  · 算完可以点"复制结果"或"导出报告"

  有 9 个计算器：QALY、ICER、INMB、PSA、单因素敏感性分析、
  折现、预算影响、决策树、成本-效益、疾病成本。

■ 3. 系统学习

  左边点"学习路径"，从第 1 步开始。
  每一步都有"学什么"和"动手做"，学会一步点一下打勾，
  进度会自己记住，下次打开还在。

■ 4. 交作业前自查

  左边点"自检清单"，用 CHEERS 2022（28 条）逐条勾一遍。
  中国指南的清单也在里面。


【关于联网和 API Key】

  默认不联网。

  · 你的提问、聊天记录、设置都只存在你自己电脑上
  · 不上传到任何服务器，不联网
  · 问出来的答案来自软件内置的知识库，每条都标了出处

  如果你想要更自然的讲解，可以在"设置"里填一个 API Key
  （DeepSeek、通义千问、Kimi、智谱等都有便宜的）。
  填了之后智能体会用大模型回答，可以多轮追问、能处理更复杂的问题。

  · Key 只存在你自己电脑上
  · 不想联网的话，设置里可以选"本机 Ollama"，完全本地运行
  · 不填 Key，其他所有功能（计算器、知识库、学习路径、自检清单）
    一样都能用


【文件放在哪】

  我的报告\        你导出的报告都在这里
  知识库\           （可选）自己加的资料，格式见说明文件
  skills\           （可选）自定义的分析流程

  软件的配置和聊天记录存在系统的应用数据目录里，
  不在这个文件夹里，但也不会上传。

  说明：这是"单文件版"软件，运行时会把程序解到系统临时目录里执行
  （这是 Windows 单文件软件的通病）。但你放报告和资料的地方
  始终是这个文件夹，不会跑到临时目录去。可以放心用。


【遇到问题怎么办】

  窗口打不开 / 白屏：
    1. 等 10 秒再试（第一次启动要解压，比较慢）
    2. 关掉再打开一次
    3. 还是不行 → 把整个文件夹复制到桌面再打开
       （中文路径有时会有问题，放桌面一般能解决）

  想确认软件本身有没有问题：
    打开软件 → 左下角「设置」→「运行自检」→「开始自检」
    十几项检查跑完会给你一张表，带 ✓ 的就是正常的。
    结果同时会存成一个日志文件（在软件的数据目录 logs 文件夹里），
    遇到解决不了的问题，把那个日志文件发出来就行。

  计算结果和老师给的不一样：
    → 打开"自检清单"里的 CHEERS 2022，对照检查你的输入
    → 常见原因：对照方案选错了、研究视角没声明、折现率不一致、
      时间和成本的范围不一致

  答案里的数字和最新政策不一样：
    → 答案下方标了出处，点"知识库"进去能看原文链接
    → 药品政策和指南每年都会更新，正式引用请以原始文件为准

  想知道软件到底算了什么：
    → 问"这个问题需要哪些步骤"，然后点回答里的"查看思考过程"
    → 设置页最下面可以看到工具清单和知识库规模


【这个软件不能做什么】

  · 不能替代原始指南和文献 —— 它是学习辅助
  · 不构成医疗、用药或医保决策建议
  · 知识库里的阈值和数字可能随政策更新而变化
  · 它不会替你做决定，只帮你把问题想清楚
